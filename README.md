# Say it Correctly

Educational website with eleven pages and five languages: English, Spanish, French, Portuguese and Simplified Chinese.

Static HTML, CSS and JavaScript. Serve the repository root over HTTP(S). Relative routes support the GitHub Pages project path `/Say-it-correctly.org/`.

Commercial services remain disabled. Contact submission, accounts and payments are not active. Parts of the Body remains the educational demonstration.

The twelve chapter cards link to the existing educational website. Those lessons and other external learning resources are hosted separately.
